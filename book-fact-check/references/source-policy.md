# Source Policy

## Evidence Priority

Use the highest suitable source in this order:

1. Local source artifacts that directly demonstrate the book's subject, including code, reproducible tests, captured output, or supplied documents
2. Official specifications, standards, manuals, API references, release notes, changelogs, and source repositories
3. Original research papers, datasets, court or government publications, and first-party statements
4. Reputable secondary reporting or expert analysis that links to its evidence
5. Community reports, forum posts, and search snippets as leads only

Marketing pages can establish what a vendor claims, but not that the claim is independently true. Search-result snippets are not evidence.

## Source-to-Claim Fit

Confirm that a source:

- addresses the same product, edition, version, platform, locale, and date
- supports the exact material claim rather than a nearby topic
- distinguishes normative specification from observed implementation
- remains available to the intended reader when it will be cited publicly

Use multiple sources when one source establishes the rule and another establishes current implementation or version state.

## Time-Sensitive Claims

Always add a checked date for facts likely to change, including:

- software versions and compatibility
- prices, plans, limits, install counts, and market statistics
- UI labels and workflows
- support, maintenance, ownership, and security status
- laws, policies, and platform requirements

Prefer wording that states the relevant version or date instead of implying permanence.

## Quotations and Numbers

- Verify quotations against the original source and preserve wording, speaker, and context.
- Check calculations independently when source data permits it.
- Preserve units, denominators, sample sizes, and date ranges.
- Treat rounded or converted values as derived claims and show the basis when material.

## Conflicts and Missing Evidence

When sources conflict, report the conflict and explain which source is stronger and why. When no primary source is found, say so plainly and retain any useful secondary evidence as a lead, not as confirmation.

Keep verbatim excerpts short. Prefer a precise paraphrase with a direct citation.
