# 7軸の編集モデル

原稿を採点するためではなく、介入が必要な意味単位を見つけるために使う。すべての軸を最大化しない。媒体、読者、目的、筆者の文体に対して十分かを判断する。

## 1. Redundancy — 重複・冗長性

### 診断

- 直前の文を抽象語で言い直している。
- 結論、理由、まとめで同じ主張を繰り返している。
- 読者に必要な補強ではなく、文章量だけが増えている。

### 編集

- 最も具体的で強い一文を残す。
- 後続文に新しい条件、根拠、例外がなければ削るか統合する。
- 学習上必要な反復、重要な警告、章をまたぐ再提示は保持する。

## 2. Density — 情報密度

### 診断

- 一文に複数の前提、条件、結論が詰まっている。
- 一段落の途中で中心メッセージが変わる。
- 読者が前半を記憶したまま後半を解釈する必要がある。

### 編集

- 条件、主張、理由の境界で分ける。
- 密接な内容は短文化のためだけに分断しない。
- 分割後、代名詞や接続関係が曖昧になっていないか確認する。

## 3. Complexity — 構文的・認知的複雑性

### 診断

- 主語と述語が離れ、対応を取り直す必要がある。
- 従属節、挿入、長い連体修飾が重なる。
- 名詞化が続き、誰が何をするのか見えない。
- 一読後に「つまり何か」を組み立て直す必要がある。

### 編集

- 行為者と動作を近づける。
- 長い前提は先行文へ出す。
- 名詞化を動詞へ戻す。ただし専門概念の名称は保持する。
- 単語を易しくするだけで概念の複雑さを隠さない。

## 4. Predictability — 展開の追いやすさ

### 診断

- 段落の途中で対象、時点、観点が無告知に変わる。
- 読者の主要な疑問より、定義や網羅的背景が先に続く。
- 指示語の参照先や、例が支える主張が分からない。

### 編集

- 読者が最初に必要とする結論または問いを早める。
- 話題転換の境界だけを明示する。
- 定義、結論、理由、例外の順は目的に合わせ、教科書的な型へ固定しない。

## 5. Specificity — 具体性

### 診断

- 「重要」「適切」「効果的」「さまざま」「柔軟」だけで評価している。
- 「これ」「その点」「対応」などの指示対象や行為が曖昧である。
- 読者が次に何を理解・実行すべきか分からない。

### 編集

- 原稿内の事実、条件、行為、対象を使って言い換える。
- 抽象語が後続の具体例を要約する役割なら残す。
- 根拠のない数値、手順、経験を追加して具体化しない。

## 6. Variation — 変化・リズム

### 診断

- 文長、段落長、構文、結論パターンが連続して同じである。
- すべての主張が同じ強さで扱われる。
- 箇条書きや見出しが過剰で、論旨が細切れになる。

### 編集

- 重要な判断には短い文、前提が必要な説明には十分な長さを与える。
- 密接な文は結合し、過密な文は分割する。
- 変化そのものを目的に語順や文長をランダム化しない。

## 7. Voice — 筆者の判断

### 診断

- 元原稿の推奨が、編集後に両論併記へ弱まっている。
- 条件付きの判断が「状況に応じて検討する」に丸められている。
- 筆者が何を重視しているか分からなくなる。

### 編集

- 元原稿の立場、優先順位、留保、確信度を同じ強さで残す。
- 強い断定へ変更する場合も、弱める場合も根拠を必要とする。
- 原稿に存在しない判断や一人称経験を作らない。

## 競合時の判断

- 短文化で精度が落ちるなら、精度を優先する。
- 具体化に新情報が必要なら、抽象表現を勝手に補わず不足を示す。
- 展開を整えると筆者固有のリズムが消えるなら、理解を妨げる箇所だけ直す。
- 反復が意図的な強調か不明なら、周囲の重要度と媒体を確認してから削る。
